# Starter СР-2

## Зависимости между пакетами

Направление зависимостей:

```text
repository → service → model
```

- `model` содержит структуру заказа `Order` и не зависит от остальных пакетов проекта.
- `service` использует `model.Order`, проверяет параметры заказа и рассчитывает стоимость доставки.
- `repository` зависит от `service`: хранит реализации интерфейса `DeliveryPricer` и предоставляет поиск тарифа по имени.

Калькулятор зависит от интерфейса `TariffRepository`, объявленного в пакете
`service`. Конкретная реализация `repository.Memory` передаётся через
конструктор `NewCalculator`. Поэтому пакет `service` не импортирует
`repository`, и циклической зависимости нет.
