# Сервис заказов

Учебный HTTP API на Go. Сервис создаёт заказы, возвращает заказ по ID и выдаёт список заказов с пагинацией. Заказы хранятся в памяти и сбрасываются при перезапуске.

## Запуск

Требуется Go 1.22 или новее. Выполните команды из каталога `Homeworks/homework_9`.

```bash
go mod download
go run ./cmd/orders
```

Сервер слушает `127.0.0.1:8080`. Контракт API доступен в [Swagger UI](http://127.0.0.1:8080/swagger/index.html) и в [формате JSON](http://127.0.0.1:8080/swagger/doc.json).

## Маршруты

| Метод и путь | Результат |
|---|---|
| `GET /api/v1/status` | `200` и `{"status":"ok"}` |
| `POST /api/v1/orders` | Создаёт заказ из JSON с полем `customer`. Возвращает `201`, JSON заказа и заголовок `Location` |
| `GET /api/v1/orders/{id}` | Возвращает заказ по положительному ID или `404`, если такого заказа нет |
| `GET /api/v1/orders` | Возвращает `200` и массив заказов по возрастанию ID |

## Пагинация

| Параметр | Допустимые значения | По умолчанию |
|---|---|---|
| `limit` | Целое число от `1` до `100` | `20` |
| `offset` | Целое число от `0` | `0` |

`offset` задаёт количество пропускаемых заказов, а `limit` — максимальное количество заказов в ответе. Например, после создания двух заказов запрос ниже вернёт массив со вторым заказом.

```bash
curl 'http://127.0.0.1:8080/api/v1/orders?limit=1&offset=1'
```

Пустая страница возвращается как `[]`. Пустые значения, числа вне допустимого диапазона, повторные и неизвестные параметры возвращают `400` с кодом `INVALID_QUERY`.
